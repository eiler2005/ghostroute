GhostRoute — architecture and recovery

Implemented components and their boundaries. The engineering register owns priorities and evidence completion criteria.

Routing

This is the default split, not every packet-level exception. LAN REDIRECT covers classified managed IPv4 TCP; managed UDP/443 is dropped. Sensitive applies only to matching requests. Endpoint DIRECT, hidden names and app-owned DNS need separate proof. Native C depends on client support; D and Amn remain labs. M uses the separate service path below.

Lifecycle ownership

This figure separates lifecycle ownership from the data plane. The guard becomes active after the firewall hook; a successful hook drill does not prove the entire reboot interval. The operator key stays on the control machine; the Console service key is constrained to a fixed report gate. Amn is outside the production supervisor.

Recovery assets

This is the recovery process, not a claim that every external copy has passed it. Exact locations, manifests and results remain private. Complete archive reads and rebuilding a spare router are separate evidence levels. Independent password recovery is required for loss of the control machine.
