GhostRoute Guard — визуальное руководство

Реализованный контракт без приватных адресов, провайдеров и снимков трафика.

Два пути в одном Chrome

Детали роутера объединены в проверенный маршрут. Неизвестные CDN/IP/TURN TCP вне каталога используют обычный путь.

Приложение управляет, Chrome исполняет

API token остаётся в нативном клиенте. Исходный внешний PAC хранится только в настройках Chrome. Общий журнал не содержит HTTP-тел.

Доступ открывается после проверки

При паузе и потере engine owned PAC/privacy остаются на закрытом gate. Новый запуск начинает автоматическую проверку; ручная пауза не хранится на диске.
