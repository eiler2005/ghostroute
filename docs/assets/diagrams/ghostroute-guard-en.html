GhostRoute Guard — visual guide

Implemented contracts without private addresses, providers or traffic snapshots.

Two paths in one Chrome

Router detail is collapsed into the qualified path. Unknown CDN/IP/TURN TCP outside the catalog use the ordinary path.

The app controls; Chrome enforces

The API token stays in the native client. External PAC source stays in Chrome settings. The shared journal contains no HTTP bodies.

Access follows successful verification

On pause or engine loss, owned PAC/privacy remain on a closed gateway. A new engine run restarts automatic verification; manual pause is not stored on disk.
